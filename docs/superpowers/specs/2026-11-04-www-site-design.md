# 三九房产官网(单页静态)设计文档

日期:2026-11-04
状态:已获用户确认

## 目标

为主域名 www.sanjiufangchan.cn 提供一个单页静态官网,满足 ICP 备案展示要求(页脚展示备案号),并展示核心卖点"39套精装房出售"。

## 方案

纯静态单文件 `index.html`(CSS 内联,无框架、无构建、无 JS 依赖)。部署方式与 `deploy-h5.sh` 一致:rsync 到远程宝塔目录。

## 页面结构(自上而下)

1. **顶部导航**:站名"三九房产" + 锚点(业务 / 关于 / 联系)
2. **Hero**:大标题"39套精装房出售" + 副标语 + 渐变背景
3. **业务板块**:三张描述性卡片(精装房源 / 房源信息 / 经纪人服务),纯文案,不接真实数据
4. **公司简介**:一段占位文案(用户后续可改)
5. **联系方式**:电话、微信、地址(占位内容)
6. **页脚**:版权信息 + 备案号 `辽ICP备2026024720号-1X`,链接到 `https://beian.miit.gov.cn/`

## 非目标

- 不接后端 API、不展示真实房源数据
- 不做多页面、不做 SEO 之外的复杂优化
- 不引入构建工具或前端框架

## 文件与部署

- 新建目录 `/data/source/fang/www/`,内含 `index.html`
- 新增 `/data/source/fang/deploy-www.sh`(仿照 `deploy-h5.sh`):
  - 无构建步骤
  - `rsync -avz --delete --exclude='.user.ini' www/ root@111.229.9.22:/www/wwwroot/www.sanjiufangchan.cn/`

## 验收标准

1. `index.html` 在浏览器直接打开可正常显示(本地文件即可验证,无需服务器)
2. 页脚包含备案号"辽ICP备2026024720号-1X",点击跳转工信部备案页
3. 移动端(约 375px 宽)与桌面端均布局正常
4. `bash -n deploy-www.sh` 语法检查通过
